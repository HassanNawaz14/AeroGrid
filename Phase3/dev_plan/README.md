## Status vocabulary

Exactly: `NOT_STARTED`, `READY`, `IN_PROGRESS`, `BLOCKED_ON_HUMAN`, `BLOCKED`,
`READY_FOR_REVIEW`, `DONE`, `CANCELLED`. "Almost done" is forbidden. Agents may set
at most `READY_FOR_REVIEW`; `DONE` requires the owner or the human with recorded
evidence.

## Tracks

- **Course track:** WP-P3-00 … WP-P3-10 — the graded deliverables.
- **Hardening track:** WP-P3-H1 … WP-P3-H4 — optional improvements to the Phase 2
  pipeline, each requiring its own decision.
