This directory is intentionally empty. It will hold the final PDF deliverables after
`G1` is cleared and the reporting work package is authorized.

- `Data_Cleaning_Report.pdf`

## Rules

- Reports must be generated from stored real-run evidence, not hand-written claims.
- Counts must match `project_dw` and `project_staging.dq_result`.
- Include source URLs, licenses, hashes, and attribution.
- Include known limitations and any critical failures.
- State that no synthetic data was used.
- Do not embed secrets, connection strings, or personal data.
- Do not commit temporary drafts; use `reports/tmp/` locally (ignored by Git).
- Report generation is owned by Member E.
